# Fence Agent Run events before projecting them to ActiveGraph

Every accepted Agent Run transition first commits to an application-owned snapshot event sequence in the Tenant Operations Store using a bounded, monotonically versioned worker lease. Only that fenced writer may then append the corresponding deterministic event to ActiveGraph's native durable stream. ActiveGraph remains the execution and replay projection used by native Packs; after interruption, a missing suffix is repaired idempotently from the snapshot, while any non-prefix divergence fails closed. Cancellation is committed atomically in the same snapshot and wins over a worker's later success or failure. This refinement of ADR 0006 prevents a stale worker from mutating ActiveGraph before losing its lease without turning LangChain or recallable Neo4j memory into workflow state.
